Назва проєкту: Офіційний веб-термінал гурту "Gathering Of The Fallen"

Основна мета: Створити професійний Full-stack сайт на React.js із повним зануренням в атмосферу постапокаліпсису. Сайт має включати магазин мерчу, музичний плеєр та розділ з лором гурту.

1. Візуальний стиль та UI/UX:

Фон: Динамічне зображення зруйнованого міста (руїни, туман, частинки попелу). Використовуй темні відтінки з акцентами іржавого металу та неонового блакитного кольору (#00FFFF) як на логотипі.

Логотип: Використовуй додане фото. Розмісти його в центрі хедеру з ефектом «мерехтіння» або «дихання» неону.

Шрифти: Для заголовків — «рваний» або металевий стиль (наприклад, Google Fonts: Nosifer, Metal Mania). Для тексту — моноширинний «хакерський» шрифт (Share Tech Mono).

Ефекти: Додай на весь сайт ледь помітну сітку (CRT scanlines) старого монітора. Кнопки та посилання повинні мати «глітч-ефект» при наведенні.

2. Функціональні розділи:

Музика (Discography): Плеєр у стилі знайденого на сміттєзвалищі старого радіо. Кожна пісня повинна мати кнопку «Lore», яка відкриває опис (наприклад, для проєкту «Забуте Я» — опис про жінку, що загубилася в пралісі).

Магазин мерчу (The Factory): * Інтегруй логіку Printful API (або аналогічної фабрики Print-on-Demand).

Товари: футболки, худі та плакати з логотипом гурту.

Реалізуй кошик та макет сторінки оплати (Stripe/PayPal).

Про гурт (About): Блок із художнім текстом про філософію виживання та музику в часи занепаду.

Стек: React, Tailwind CSS, Framer Motion (для анімацій).

Бекенд: Node.js для обробки замовлень та зв’язку з API фабрики.
